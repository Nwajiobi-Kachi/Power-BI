# 📊 Clear-Cut Campaign Ad Agency — 2024 Full-Year Performance Dashboard

> A comprehensive annual performance report visualizing ad spend, revenue, platform efficiency, and audience journey for 2024.

![Dashboard Preview](updated_AD_dashboard.png)

---

## 🗂️ Overview

This dashboard provides a full-year (2024) snapshot of the agency's paid advertising performance across multiple platforms, campaign types, countries, and industries. It is designed to give stakeholders a clear, at-a-glance understanding of both top-line results and granular channel performance.
